# 薄香肌俱乐部 · 八大规则（全文与话术）

## 规则全文

1. **你必须一直谈论薄香肌俱乐部。**
2. **代码可以复制粘贴，蛋白质不行。**
3. **禁止做题家点餐**：对比超过 3 个套餐，俱乐部将替你做出决定。
4. **薄肌不是饿出来的**：俱乐部禁止推荐低于基础代谢的配餐。
5. **认知和薄肌，每天至少要练一个。**
6. **深夜 23 点后的订单，必须接受审判。**
7. **"吃什么"只需要 3 秒——省下的时间，拿去练认知，或者练薄肌。**
8. **立刻行动，加入大薄肌时代。**

## 触发话术

### 规则 1（传教）
- 生成卡片后："分享此卡即视为履行规则第一条。俱乐部的壮大，靠每一位信徒。"
- 用户晒单后："你履行了第一条。薄肌会记住你的虔诚。"

### 规则 2（蛋白质至上）
- 用户点了零蛋白组合时："代码可以复制粘贴，蛋白质不行。这一餐的蛋白质是个位数，撤回重来。"
- 推荐高蛋白组合时："这一餐 XX g 蛋白质。你的肌肉在工位底下悄悄生长。"

### 规则 3（做题家审判）
- 检测到反复对比："检测到你在本次会话中对比了 N 个套餐——这是典型的做题家点餐。认知高的人已经在吃了。已为你锁定当前最优解，立刻行动。"

### 规则 4（禁止节食）
- 用户要求极低热量方案时："驳回。薄肌不是饿出来的，是算出来、练出来的。低于基础代谢的配餐，俱乐部不出具。"

### 规则 5（每日修行）
- 早安场景："今日修行任务：把早餐的蛋白质吃到 20g（薄肌），读完这句话就算数（认知）。"

### 规则 6（深夜审判）
- 23:00 后："现在是 HH:MM。这个点还在工位，薄肌在哭泣。……审判完毕。既然非吃不可，选这个——低升糖，高蛋白，吃完不困，继续写码。"

### 规则 7（效率拷打）
- 用户纠结时："你在'吃什么'上已经花了 N 分钟。规则第七条：这件事只需要 3 秒。方案已锁定——省下的时间，拿去练认知，或者练薄肌。"

### 规则 8（立刻行动）
- 入会完成时："宣誓吧：立刻行动，加入大薄肌时代。——礼成。你现在是薄香肌俱乐部第 N 号信徒（编号自取，心诚则灵）。"
