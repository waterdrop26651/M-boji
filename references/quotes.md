# 认知金句库

按日期轮转使用（day % 总数）。店长可结合当日活动二次创作，但不得偏离俱乐部精神。

## 薄肌篇

1. 薄肌不是饿出来的，是算出来、练出来的。
2. 你点的不是麦满分，是对糊弄的早餐发起的代码审查。
3. 肌肉不会辜负每一次深蹲，就像测试不会辜负每一行断言。
4. 脂包肌是技术债，薄肌是重构后的核心代码。
5. 健身房的重量不会说谎，就像生产环境的日志。
6. 你的腹肌藏脂肪后面，就像你的才华藏在 TODO 注释后面。
7. 蛋白质是身体的编译器，没有它，肌肉永远无法构建。
8. 每一次拒绝含糖饮料，都是一次成功的依赖瘦身。
9. 薄肌是少数不会被裁员的资产。
10. 别人收藏健身视频，你收藏蛋白质。

## 认知篇

11. 复制粘贴的代码会报错，复制粘贴的人生会发胖。
12. debug 一夜不是勤奋，是用战术的勤奋掩盖认知的懒惰。
13. 选择困难不是因为选项太多，是因为你还没想清楚要什么——点餐如此，人生亦然。
14. 你纠结 20 分钟点的餐，和 3 秒点的餐，热量是一样的。
15. 信息茧房的第一步，是每天中午吃同一家外卖。
16. 认知升级从不转发锦鲤开始。
17. 你以为你在点餐，其实是你的习惯在点你。
18. 拒绝学生思维：没有标准答案，只有此刻最优解。
19. 真正的自由不是想吃啥吃啥，是知道自己在吃啥。
20. 人生没有 ctrl+z，但下一餐永远可以优化。

## 程序员篇

21. 别人问程序员有什么爱好，我说：commit、push、吃够蛋白质。
22. 久坐是程序员的慢性病，薄肌是处方。
23. 工位到取餐柜的 200 米，是今天唯一的 CI/CD——Continuous Improvement / Continuous Dining。
24. 代码可以跑就行，身体不行。
25. 上线前最后一餐，别吃到犯困——回滚套餐：高蛋白，低升糖。
26. 你的颈椎、腰椎和腹肌，都是不可逆的线上环境。
27. 程序员的三层架构：代码层、认知层、薄肌层。大部分人的第三层 404。
28. 别让久坐成为你唯一坚持下来的运动。
29. 凌晨的 PR 和凌晨的炸鸡， merge 之前都要三思。
30. 写代码追求高内聚低耦合，吃饭追求高蛋白低升糖——架构思想是相通的。

## 深夜审判专用

31. 这个点的麦当劳，吃的是生活，审判的是作息。
32. 夜晚会原谅你的饥饿，但不会原谅你的摆烂。
33. 深夜食堂可以有，深夜emo不行。吃完这顿，回家睡觉。
